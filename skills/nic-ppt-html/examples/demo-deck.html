面向 Cursor / Claude Code / Codex 的开发者工具技能集：脚本优先、先自用、输出落在品牌目录。

deck-type: architecture · style: project-brand + tech-dark · 2026-08-12

Agenda

今天讲清三件事

  • 为什么需要 nic- 前缀的原子技能，而不是巨型提示词包
  • 当前技能如何协作：预览 · 生图 · 代码出图 · 报告 · PPT
  • 设计原则与安装方式，以及下一跳候选技能
Problem

Agent 工作流里，摩擦往往不在模型，而在确定性步骤

  • file:// 预览被 IDE 拒绝，临时起 server 又留下僵尸进程
  • 图表 / 报告 / 截图路径散落，难以复用与 git 友好沉淀
  • 全仓安装技能会污染上下文；需要 单技能按需安装
Positioning

一个技能只做一件事；能脚本化的不靠临场发挥。

Brand: NicSkills · Prefix: nic- · Install: npx skills add nickylin/NicSkills --skill nic-xxx

Principles

Install

推荐单技能安装，避免上下文膨胀

# 示例：安装 PPT HTML 技能
npx skills add nickylin/NicSkills --skill nic-ppt-html

# 本地 dogfood（symlink）
ln -sfn "$(pwd)/skills/nic-ppt-html" ~/.cursor/skills/nic-ppt-html
